# 🎭 Theater Play – Static Landing Page :-

A responsive and accessible **Static Landing Page** developed using **HTML5, CSS3, and Vanilla JavaScript**. This project was created as part of an internship client deliverable and focuses on clean UI, responsive design, accessibility, and basic client-side validation.
